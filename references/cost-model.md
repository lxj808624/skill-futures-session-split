# 成本口径

## 1. 计算方式

一次完整往返（开 + 平）的成本，单位 bp（万分之）：

```
round_turn_bp = commission_bp + 2 × slippage_ticks × tick / price × 10000
```

- `commission_bp`：手续费，按**名义价值**计，双边合计；
- `2 ×`：开仓一次、平仓一次；
- `tick / price`：一个最小变动价位占价格的比例。

## 2. 取值

| 交易所 | 品种 | commission_bp |
| --- | --- | --- |
| SHF | RB CU AU AG | 2.0 |
| DCE | I M | 2.0 |
| CZC | TA MA | 2.0 |
| INE | SC | 2.0 |
| GFE | LC | 2.0 |
| CFE | IF T | 1.0 |

滑点默认 1 tick / 边；敏感性测试 0 / 1 / 2 tick。

## 3. 声明

> 以上为**常规行业假设**，不是原 Q2 交付物的实测口径。Q2 的成本字段未取得，本研究的增量结论只作方向性参考，不与 Q2 的具体数字直接相加比较。

取得 Q2 原始口径后：只改 `config/varieties.yaml` 的 `commission_bp`，代码与规则不变。

## 4. 未纳入的成本项

- 保证金占用成本（资金利息）
- 涨跌停、流动性不足导致的无法成交
- 盘中强平、追保
- 交割、仓储、移仓的额外费用
- 交易所手续费减免/返还

这些项会让真实成本**高于**本研究的估算，因此本研究对「时段效应能否覆盖成本」的判断偏乐观；报告需注明该方向性偏差。

## 5. 成本敏感性检查

至少报告三档：

| 档位 | 用途 |
| --- | --- |
| 0 tick | 纯信号效应上界 |
| 1 tick | 基准判断 |
| 2 tick | 压力测试 |

若某规则仅在 0 tick 下占优、加 1 tick 后排名跌落，则该结论标记为「成本脆弱」，不得作为推荐。
