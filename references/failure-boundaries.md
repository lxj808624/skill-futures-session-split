# 使用与失败边界

## 1. 能做什么

- 期货分钟行情的三段拆分（夜盘 / 日盘 / 闭市跳空）
- 同一冻结信号下四种持仓窗口的对比（B0 / B1 / B2 / B3）
- 成本敏感性（0 / 1 / 2 tick）
- 交易日归属校验（平台字段 vs 日历推算）
- 样本内外稳定性与排名翻转检查

## 2. 不能做什么

| 限制 | 原因 |
| --- | --- |
| 不挖掘新的日内信号 | 属 Q3 范畴；本期信号冻结 |
| 不在复权/连续价上算盈亏 | 跨合约收益是假的（Q2 硬约束） |
| 不重建回测引擎或策略注册表 | 引用 Q15 的统一基准 |
| 不覆盖非期货品种 | 时段定义只对期货有效 |
| 不给出投资建议 | 研究结论只描述统计特征 |

## 3. 失败边界（逐个对照现象与处置）

| 现象 | 判定 | 处置 |
| --- | --- | --- |
| PandaData 登录报 `错误码 200006 : 用户未注册` | 凭据无效或未授权 | 改在 QuantStudio 平台内走 OAuth，不在本机直连 |
| 分钟数据行数远少于预期 | 品种停盘、接口截断或区间无数据 | 先查交易日历，再拆分区间重取；不缓存截断结果 |
| 夜盘 bar 的 `trading_date` 与日历推算不一致率 > 1% | 数据源归属异常 | 终止研究，报告数据问题 |
| 某品种某日分钟数 < 常态 90% | 不完整交易日 | 标记并从回放中剔除，数据质量表列明 |
| 三段恒等式偏差 > 1e-9 | 分段逻辑 bug | 停止出表，先修 `sessions.py` |
| 主力合约在某段内切换 | 换月污染 | 该交易日记入污染窗口，另出剔除版本 |
| 实际合约在区间内无有效报价 | 合约到期或未上市 | 该品种该段跳过，不猜测、不用其他合约替代 |
| OOS 区间内规则排名翻转 | 结论不稳定 | 报告标注不可靠，不推荐该规则 |
| 加 1 tick 后最优规则变化 | 成本脆弱 | 标注「成本脆弱」，只保留方向性结论 |
| 平台内无法运行 shell / 装包 | 比赛会话限制 | 用等价回放，明确声明回放范围 |

## 4. 已知未验证项

- `fetch_minute.py` 的换月切段逻辑未在真实授权下跑过（本机凭据被服务端拒绝）。
- `get_future_dominant` 的返回字段未实测，代码做了字段自适应（`dominant_id | trading_code | symbol | code`，日期列 `date | trading_date`），首次真实运行需人工核对。
- 各品种手续费 bp 为常规假设，非交易所实测值。

## 5. 复跑前置条件

1. Python 3.10+，安装 `requirements.txt`
2. 有效 PandaData 授权（平台 OAuth）
3. 数据落在 `outputs/raw/<code>.parquet`，字段含 `datetime / trading_date / open / high / low / close / volume / open_interest`
4. 先跑 `python scripts/selfcheck.py`，全绿再取数
