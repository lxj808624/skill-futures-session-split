## 1. 研究问题与预注册假设

**问题**：期货日内收益到底来自哪一段——夜盘、闭市跳空、日盘？把持仓窗口固定成规则后，哪一段在扣成本后仍可交易？

| 编号 | 假设（先验、可被证伪） | 证伪条件 |
| --- | --- | --- |
| H1 | 隔夜段（昨收→今开）贡献了大部分收益，但风险与跳空暴露集中在此 | 隔夜段年化 / 日盘段年化差异 < 20%，或按风险调整后无差异 |
| H2 | 日盘段（今开→今收）扣掉双边成本后不显著为正 | 日盘段扣成本后 t < 1.65 或年化为负 |
| H3 | 闭市跳空段（夜盘收→日盘开）近似无漂移，方差占比高 | 跳空段均值显著非零（t > 2） |
| H4 | 隔夜过滤（跳空/夜盘方向门控）在样本外仍有增益 | OOS 相对 B0 的增量 < 0 或不显著 |
| H5 | 品种间存在结构性差异（有夜盘 / 无夜盘、长夜盘 / 短夜盘） | 分组后差异不显著 |

预注册纪律：规则参数只允许来自先验（整数、常识阈值），不允许用全样本网格搜索选参；参数敏感性只作为稳健性检查，不据此改主规则。

## 2. 口径定义（硬约束）

### 2.1 交易日归属

- 一律使用行情自带 `trading_date`，不自行推断。
- 夜盘 bar（21:00–02:30）的 `trading_date` 是**下一个交易日**；周五夜盘归下周一（遇节假日顺延）。
- 校验项：夜盘 bar 的 `date`（自然日）与 `trading_date` 不一致条数、周五夜盘→周一的映射条数、节假日前后映射抽样。异常条数写入 `outputs/attribution_check.json`。

### 2.2 三段收益分解（按交易日 t）

设 `C_{t-1}` 为上一交易日 15:00 收盘，`N_t` 为本交易日夜盘最后一根收盘，`O_t` 为日盘第一根开盘，`C_t` 为日盘最后一根收盘：

| 段 | 定义 | 说明 |
| --- | --- | --- |
| 夜盘段 | `N_t / C_{t-1} - 1` | 含夜间连续交易；无夜盘品种为空 |
| 闭市跳空 | `O_t / N_t - 1` | 夜盘收 → 早盘开（含节假日空档） |
| 日盘段 | `C_t / O_t - 1` | 早盘开 → 收盘 |
| 全天 | `C_t / C_{t-1} - 1` | 恒等式：`(1+夜)(1+跳空)(1+日) - 1` |

无夜盘品种（股指、国债）：跳过夜盘段，跳空段改为 `O_t / C_{t-1} - 1`，报告中单独分组标注。

### 2.3 缺失与停盘

- 每个交易日按"该品种期望分钟网格"计算覆盖率；期望网格由全样本中出现频率 ≥90% 的分钟点求得（不写死交易所规则，规则只用于交叉核对）。
- 覆盖率 < 80% 的交易日标记 `incomplete`，不进入收益统计；整日无 bar 标记 `halted`。
- 输出每日、每品种的缺失分钟数、缺失时段（夜盘/日盘/跳空边界），不静默填补。

## 3. 数据与合约口径

| 项 | 口径 |
| --- | --- |
| 行情 | PandaData `get_future_min`，1 分钟，字段：symbol / datetime / trading_date / open / high / low / close / volume |
| 合约 | 主力合约映射 `get_future_dominant`，按区间取实际合约（如 `RB2610.SHF`），不拼接连续合约 |
| 换月 | 换月当日不计算跨合约收益；换月前后各留 1 个交易日缓冲，单独统计换月影响 |
| 样本 | 2021-01-04 ~ 2026-10-30，样本内 2021–2024，样本外 2025-01 ~ 2026-10 |
| 品种 | 12 个：RB / CU / AU / AG（上期所）、I / M（大商所）、TA / MA（郑商所）、SC（能源中心）、LC（广期所）、IF / T（中金所） |
| 成本 | 常规口径：手续费按名义价值双边 2 bp（商品）/ 1 bp（金融），滑点 1 tick/边；三档 0 / 1 / 2 tick 敏感性 |
| 时区 | 一律北京时间；bar 时间按收盘时刻解释（15:00 那根覆盖 14:59–15:00） |

- 品种参数（乘数、tick、手续费）写入 `config/varieties.yaml`，每条注明来源与核对日期；未核实项标 `待核实`，不得用其他品种推测。
- 无夜盘品种的"隔夜"只含闭市跳空，报告中不与有夜盘品种混算。

### 3.1 成本与换月口径声明（必须原样进报告）

Q2 交付物未取得，本研究的成本与换月参数**均为行业常规假设，不是 Q2 的实测口径**。声明如下：

| 项 | 取值 | 性质 |
| --- | --- | --- |
| 价格 | 实际主力合约成交价，不做复权、不拼接连续价 | 硬约束（继承 Q2：不能用复权价算盈亏） |
| 换月 | 持仓量确认换月；换月日及前后各 1 个交易日单列，另出「剔除换月」对照 | 常规做法（继承 Q2 的换月敏感结论） |
| 手续费 | 名义价值双边 2 bp（SHF/DCE/CZC/INE/GFE）、1 bp（CFE） | 常规假设，标注非 Q2 实测 |
| 滑点 | 1 tick / 边；敏感性 0 / 1 / 2 tick | 常规假设 |
| 收益口径 | 百分比收益、按手数折算；不含保证金占用、涨跌停无法成交、盘中强平 | 边界声明 |

> 因此「相对基线的作用多大」只作方向性参考，不与 Q2 的具体数字直接相加比较。取得 Q2 原始口径后，只需替换 `config/varieties.yaml` 的成本字段，规则与代码不变。

## 4. 规则集（必须形成持仓规则）

| 编号 | 规则 | 持仓窗口 | 换手 |
| --- | --- | --- | --- |
| **B0** | 全天持有：每日收盘建仓，持有到下一交易日收盘 | 夜盘 + 跳空 + 日盘 | 连续持有，仅首尾各一次成本 |
| **B1** | 仅日盘：日盘开盘建仓，收盘平仓，隔夜空仓 | 日盘 | 每日 2 次 |
| **B2** | 隔夜过滤-A（跳空门控）：夜盘开盘跳空的绝对值 ≤ 阈值 τ 时才持有夜盘段（捕获夜盘、不捕获跳空本身），否则空仓过夜、次日日盘照常 | 夜盘（条件） + 日盘 | 条件性 |
| **B3** | 隔夜过滤-B（夜盘动量门控）：前一交易日夜盘段上涨才顺势持有隔夜（含跳空段），否则空仓过夜 | 夜盘 + 跳空（条件） + 日盘 | 条件性 |
| **D1** | 日盘跳空过滤：\|跳空\| > τ 时跳过当日日盘，否则做日盘 | 日盘（条件） | 条件性 |

> **无前视约束**：B2 的跳空在夜盘开盘即已可观测，B3 只用前一交易日夜盘方向（滞后 1 期）。任何门控都不得使用当日尚未发生的收益；`rule_returns` 按此实现。
| **D2** | 三段择时对照：只在夜盘段、只在跳空段、只在日盘段持有（理论上限，用于归因，不作策略） | 单段 | — |

- τ 取先验整数（如 0.5% / 1.0%），不按样本调优；敏感性用 0.25% / 0.5% / 1.0% / 2.0% 展示。
- D2 是归因工具，报告中明确"不可交易"，不进评分结论。

## 5. 评估方法

- 指标：年化收益、年化波动、Sharpe、最大回撤、日胜率、日均收益（bp）、成本拖累（bp/日）、换手率、t 统计量、bootstrap 95% CI（block bootstrap，块长 20）。
- 组合口径：12 品种等权，逐日再平衡；品种内按 1 手折算收益（百分比），避免手数差异影响。
- 成本模型：`成本 = 换手次数 × (手续费 + 滑点 tick × tick 价值) / 名义价值`，折算为 bp。
- 样本外：IS 定规则（只用先验），OOS 只做验证，不允许在 OOS 上再调参；输出 IS/OOS 并列表与逐年表。
- 多重检验：主检验只有 H1–H4 四条，其余为描述统计；不做大规模网格，避免 p-hacking。
- 稳健性：成本三档 × 参数四档 × 分组（有/无夜盘、夜盘长短）；结论需在多数格点上同号。

## 6. 冻结基线对照（Q2 口径）与 Q15 形态

**基线对象**：按 Q2 的固定规则比较框架重建的 B0 —— 信号冻结不变（每日收盘建仓、持有到下一交易日收盘），只比较执行与持仓口径，用实际合约价格结算，成本按 3.1 的常规口径。

**与三期的关系**（避免重复）：

| 题 | 维度 | 本期如何引用 |
| --- | --- | --- |
| Q2 | 换月规则 | 继承「同信号、只换规则、实际合约、不复权」骨架；固定持仓量确认换月，换月日单列 |
| Q3 | 通用日内信号 | 不重复做日内信号；本期只拆时段与持仓窗口 |
| Q15 | 统一基准 | 借用其交付形态：一键基准、差异账本、版本指纹、排名翻转检查，不重建回测引擎 |

**三件交付（按 Q15 形态）**：

1. **差异账本** `baseline_compare.csv`：每条规则相对 B0 的年化、Sharpe、回撤、成本拖累、日均 bp 差值，IS / OOS 各一套。
2. **版本指纹** `fingerprint.json`：数据（品种、合约段、区间、行数）、配置（成本档、τ、换月规则）分别做 SHA-256，复跑可对齐同一版本。
3. **排名翻转检查** `rank_flip.csv`：在「成本 0 / 1 / 2 tick × 换月含 / 剔除 × IS / OOS」三个方向共 12 个格点上，记录规则排名；排名翻转即在报告中标注该结论不可靠。

**增量口径**：Δ = 规则 − B0，配 bootstrap 95% CI；不把常规假设成本下的 Δ 与 Q2 原数字直接相加。

## 8. 平台执行与记录

1. 启动 QuantStudio 本机服务，连接 PandaData（浏览器 OAuth）。
2. 将本 skill 安装进能力库，在普通研究会话中调用，输入（品种、区间、成本档）与输出（CSV/JSON/报告）落在 `outputs/`，形成输入输出索引。
3. 交易执行核验：以模拟盘等价回放（规则目标持仓 → 实际合约手数），不接真实下单；不可交易品种（如流动性不足、无对应主力）在报告中明确排除原因。
4. 若平台接口不支持某些品种/周期，报告"等价回放范围"：哪些品种用日线近似、哪些品种整段排除。

## 9. 失败边界（必须写进 README）

- 数据缺失：覆盖不足的交易日直接剔除并计数，不插值、不补齐。
- 换月：跨合约收益不可比，换月日不进入统计；主力映射为空时该品种停更并标记。
- 无夜盘品种：不参与"夜盘段"横截面比较。
- 平台不支持：PandaData 未授权、接口变更、数据截断 → 停止并报错，不出替代结果。
- 结论边界：本研究的收益为成本后百分比口径，不含保证金、资金占用、涨跌停无法成交等约束；结论不外推到未测品种与未测周期。
