# 成本口径修正（v3）：两处记账错误与等成本重算

> 本文件取代 `docs/研究报告.md` §4 / §5 里的 B0、B2、B3 收益数字。§4/§5 的表格保留为 v2 留痕，**结论以本文件为准**。
> 触发原因：R6 严格复核逐行读 `scripts/evaluate.py` 的 `turns` 赋值时发现，成本不是「按窗口统一」，而是「按规则各记各的」。

## 1. 两个错误

### 1.1 B0（全天持有）没有计成本

```python
if rule == "B0":
    gross = df["r_full"]
    turns = 0.0          # ← 旧版
```

B0 的定义是「夜盘开盘建仓、日盘收盘平仓」，这本身就是**一个完整往返**：开一次、平一次。旧版把 `turns` 记成 0，于是 `net_bp = gross*1e4 - turns*cost_bp` 里的成本项恒为 0，B0 的 +24.77% 是**毛收益**；而 B1/B2/B3/D1 都是净收益。基准不带成本、对手带成本，两者不可比。

### 1.2 B2 / B3 的成本记在空仓日

```python
elif rule == "B2":
    gross = day + np.where(gap & has_night, night, 0.0)
    turns = np.where(gap & has_night, 0.0, 1.0)     # ← 旧版：持仓记 0、空仓记 1
elif rule == "B3":
    keep  = prev_night_up & has_night
    gross = day + np.where(keep, night + gap, 0.0)
    turns = np.where(keep, 0.0, 1.0)                # ← 同一个方向写反
```

对照 D1（`turns = np.where(gap, 1.0, 0.0)`，达标日才计成本）可见三者的 `turns` 语义本应一致：**交易日 = 1 个往返，空仓日 = 0**。B2/B3 写反后，成本被计在没交易的日子，等于给「交易最多的规则」打折：B2 每日都做日盘、成本却只按 26.7% 的交易日计（1.76bp），B3 按 62% 计（4.10bp）。

## 2. 修正口径

统一为「当日建立并平掉一次仓位 = 1 个往返，成本 = 1 × cost_bp(品种, 日盘收盘价)」：

| 规则 | 每日是否建仓 | turns |
| --- | --- | --- |
| B0 全天持有 | 夜盘开、日盘收 | 1 |
| B1 仅日盘 | 日盘开、日盘收 | 1 |
| B2 跳空门控 | 每日做日盘，跳空达标时连做夜盘 | 1 |
| B3 夜盘动量 | 每日做日盘，门控通过时连做夜盘＋跳空 | 1 |
| D1 跳空过滤日盘 | 仅在跳空达标日做 | 达标 1 / 否则 0 |

保守说明：B3 门控通过时仓位跨日连续持有，理论上换手低于每日 1 次；本版**不做折减**，仍按 1 次计，属于偏保守（对 B3 不利）的处理。

实现：`scripts/evaluate.py` 已按上表修正（见文件内 `修正（v3）` 注释），复算脚本为 `scripts/cost_audit.py`，输出 `outputs/cost_audit_corrected.json`。（本机无 numpy/pandas，`cost_audit.py` 只用标准库，直接读两块落盘面板 `outputs/panel_daily.csv` 与 `outputs/is_oos_b12/panel_daily.csv`。）

## 4. 修正后结论（**取代 v2 的三条读数**）

1. **v2 的核心对比失效**。v2 写「B1 与 B0 差 13.4bp/日，其中 6.58bp 是可计成本，剩下 6.8bp 是日盘负漂移」——这个分解只有在 B0 不计成本时成立。等成本后，两个窗口的成本项相同、相互抵消，**窗口之间的差只剩 6.8bp/日的日盘段本身**；「成本占 16.6pp/年」的说法不成立（成本对两个窗口同额扣减，不构成二者差异）。
2. **B2「保留 56% 收益」的说法不成立**。v2 的 B2 +13.89% 是「按 26.7% 交易日计成本」的产物，修正后为 +0.07%/年、日均 +0.16bp，与 0 无差别。跳空门控的价值从「低成本保留一半收益」降级为「与不做几乎没有差别」。
3. **22 个月样本上，五条规则全部为负**。v2 的「全天持有 OOS +10.32%」是基准不扣成本的毛收益；修正后 B0 全样本 -11.42%、OOS -6.37%。**唯一统计显著的是「日盘暴露亏钱」**：B1（t=-3.99）、D1（t=-4.06）、B3（t=-3.35）、B2（t=-2.66）在 441 天上都显著为负，且都是因为含日盘暴露。
4. **可靠结论收紧为一条**：在 12 品种、22 个月、1 tick 滑点、含换月窗口的口径下，**没有任何一种持仓窗口（含全天持有）取得正收益**；差异只在亏多亏少。原 v2 的「B0/B2 > B3 > D1 > B1」排序依然成立，但整体水平从「正的基准」下移到「全负」，因此它**不构成可上线的交易结论**，只构成「日盘暴露是成本与负漂移的来源」这一结构判断。

## 5. 对价值 V 的影响

- 改变的决策更明确：**任何「全天持有 +25%/年」的回测展示，若基准未计自己的往返成本，都会系统性高估约 16pp/年**（6.58bp × 252 ≈ 16.6pp）；本项修正给出的是这条偏差的实测大小与它如何翻转逐规则排序。
- 同时暴露了第二种更隐蔽的错误：门控类规则把成本记在空仓日，会让「交易越频繁的规则」看起来成本越低。这两类错误都不需要新数据就能犯，属于**成本记账层面的通用陷阱**，可迁移到任何时段/换手研究。
- 边界：成本为常规假设（2bp 手续费 + 1 tick 滑点），非交易所实测；5 分钟频率带来 ≤5 分钟时段边界误差；83 天样本的检验能力约 18bp/日。
