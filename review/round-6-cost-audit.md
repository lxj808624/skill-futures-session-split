# R6 严格复核：成本记账逐行审计（发现两处实质错误）

复核时间：2026-11-18 17:20
复核方式：不读结论、只读代码。把 `scripts/evaluate.py` 的 `rule_returns()` 逐行对照规则定义表，检查「每个规则每天到底建了几次仓、成本记在哪一天」。
结论：**不通过**，两处记账错误，结论方向被系统性抬高。已修正并重算，交付改 v3。

## 1. 错误一：B0 基准不带成本

证据（`scripts/evaluate.py` 旧版）：

```python
if rule == "B0":
    gross = df["r_full"]
    turns = 0.0
```

而规则表定义 B0 = 「夜盘开盘建仓、日盘收盘平仓」——开一次、平一次 = 1 个完整往返。`net_bp = gross*1e4 - turns*cost_bp`，`turns=0` 使成本项恒为 0。

后果：B0 的 +24.77%/年（A）与 +10.32%（B/OOS）都是**毛收益**，而同桌的 B1/B2/B3/D1 全是净收益。差额 6.58bp/日 ≈ 16.6pp/年 全被记在对手一侧，于是报告读成了「B0 赢 B1 是因为 B1 交了 6.58bp 成本」。

## 2. 错误二：B2 / B3 的成本记在空仓日

```python
elif rule == "B2":
    gross = day + np.where(gap & has_night, night, 0.0)
    turns = np.where(gap & has_night, 0.0, 1.0)   # 持仓→0，空仓→1
elif rule == "B3":
    keep  = prev_night_up & has_night
    turns = np.where(keep, 0.0, 1.0)              # 同一方向写反
```

对照 D1（`turns = np.where(gap, 1.0, 0.0)`，达标日才计）可见三段代码的 `turns` 语义本应统一为「交易日 1、空仓日 0」。B2/B3 写反后，成本被计在没交易的日子：B2 每日都做日盘，成本却只按 26.7% 的交易日计（1.76bp/日），B3 按 62% 计（4.10bp/日）。

后果：B2 +13.89%、B3 +3.23% 都被少扣约 3–4.8bp/日；「B2 用 1.76bp 成本保留 56% 收益」是这条错误的直接产物。

## 3. 修正与重算

- 代码：`scripts/evaluate.py` 三处 `turns` 改为 1.0（文件内标 `修正（v3）`），B2/B3 保留「每日 1 往返」的保守口径，不对跨日连续持仓折减换手。
- 复算：`scripts/cost_audit.py`（纯标准库，读已落盘面板，不依赖 numpy/pandas），输出 `outputs/cost_audit_corrected.json`、`outputs/summary_v3.csv`、`outputs/is_oos_v3.csv`。
- 交叉核对：B1 的新旧数字必须一致（成本口径没动）——旧 -3.241bp/日、新 -3.242bp/日，差 0.001bp，说明复算链路与 v2 是同一套数据。

## 4. 结论如何变化

| 项 | v2 | v3（等成本） |
| --- | --- | --- |
| A 样本 B0 | +24.77%（毛） | +8.93%（净），t=0.55，CI [-3.75, +7.79] |
| A 样本 B2 | +13.89% | +0.07% |
| A 样本 B3 | +3.23% | -3.93% |
| B 样本 B0 | IS -0.20% / OOS +10.32% | IS -15.41% / OOS -6.37% |
| B 样本 B1 | -22.70% 级 | -22.70%（不变） |
| 主线 | 「全天持有赚钱，过滤器不确定」 | 「五窗口全负，唯一显著的是日盘暴露亏钱」 |

**保留的判断**：日盘暴露亏钱（B1 t=-3.99、D1 t=-4.06）在修正后更强，因为它本来就带成本；「夜盘赚钱是品种 β」的归因基于分品种 gross 拆解，不受成本口径影响，仍然成立（LC/AG/AU/IF 占 92.8%）。

**作废的判断**：「成本占 16.6pp/年」「B2 保留 56% 收益」「B0 是唯一正收益基准」「样本 B 头名 B0 稳定第一」——最后一条方向仍对（B0 排序第一），但水平从正下移到全负。
